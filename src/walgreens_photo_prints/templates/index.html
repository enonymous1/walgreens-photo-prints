Photo prints, from the browser

This is a front-end for the Walgreens Native Photo Prints API v3 client. Browse products, find stores, validate a coupon, upload an image, submit an order, and check its status.

Submit is a two-step flow everywhere: first a preview with the API key redacted, then a second confirmation with the customer terms action checked. Without both, nothing is submitted.

  • Products — list products and prices.
  • Stores — find photo stores near a location.
  • Coupon — validate a coupon against a cart.
  • Upload — upload one image via fresh credentials.
  • Submit — preview, then submit a real order (live mode only).
  • Status — check orders by vendor order ID.
